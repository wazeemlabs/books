# Literature archive index

Compiled on 2026-09-26 for the CARE (checksum-aided recall with eviction) project. Every arXiv ID cited in `docs/literature.md` or `docs/vs_rag.md`, every paper found in the follow-up searches, and every paper already saved in `sources/` is listed here.

How it was built:

- Each arXiv ID was checked against the arXiv API (`export.arxiv.org/api/query`). All 62 exist; titles, authors and first-version years below come from the API.
- Each PDF was downloaded from `arxiv.org/pdf/<id>` with a 2 s gap between requests and saved to `<topic>/pdf/<id>.pdf`. Text was extracted with `pdftotext` (poppler), NFKC-normalised, and stripped of control and private-use characters so it is grep-able. Each `<topic>/<id>.md` has the URL on line 1, the title on line 2, then authors, the arXiv abstract, and the full text with `--- Page N ---` markers (PDF page numbers).
- Earlier abstract-only files and `-full` duplicates were replaced, so each paper has exactly one `.md`.
- Non-arXiv items: Talbot & Osborne from the ACL Anthology, the six Sleeping LLM reports from the Zenodo API, the neuroscience papers as metadata plus abstract (Crossref or PubMed) with DOI links.
- Topic, closeness and relevance were judged by reading each paper's abstract and the relevant sections, together with the overlap notes in `docs/literature.md`.

Closeness to CARE: 5 = same mechanism, 1 = distant, "background" = theory or evidence we build on rather than a competing method. `docs/literature.md` gives no numeric scores, so scores without a mark were set in the research brief; scores marked `*` were judged while compiling this index.

Venues come from the arXiv journal-ref or comment field, or from the PDF's first page. Where the docs name a venue that neither source confirms, the entry says so.

FOUND.** Section 3.4, "Write-back as slow consolidation", PDF page 6: "A fact is removed from external memory only if consolidation is validated, i.e., the updated model answers its probes correctly without retrieval: (1/m_i) Σ_j EM(Ans_Θ′(q_ij), a_ij) ≥ τ_flush. Otherwise, it remains in external memory." The next sentence names the cycle: "initial externalization into E, subsequent internalization into Θ′, and final eviction from E." (The formula is rebuilt from the PDF's broken math layout.)
2. **2508.16983, ReFactX: the model is prompted to answer "I don't know". FOUND.** Figure 4, the Wikidata system prompt, PDF page 9: "If you didn't find proofs with "Fact:" that support an answer you stop and you reply: "I don't know."." Section 4, "Embedding ReFactX into Question-Answering Workflows", same page: "we instruct the model ... to respond "I don't know." when no useful facts have been found". It is an instruction in the prompt, not a trained or verified behaviour. On PDF page 10, precision excludes "I don't know" answers from the denominator.
3. **2512.19134, QuCo-RAG: zero entity co-occurrence flags hallucination and triggers retrieval, not abstention. FOUND.** Abstract, PDF page 1: "during generation, we verify entity co-occurrence in the pre-training corpus, where zero co-occurrence often signals hallucination risk. Both stages leverage Infini-gram for millisecond-latency queries over 4 trillion tokens, triggering retrieval when uncertainty is high." Section 1, PDF page 2: "zero co-occurrence triggers retrieval and regeneration." Section 3.3, "Runtime Claim Verification", PDF page 4: "Retrieval is triggered if the co-occurrence count falls below a threshold τcooc (default set to 1)" and "if two entities never co-occur in the pre-training corpus, the generated claim lacks evidential support and likely constitutes a hallucination". The full text never uses "abstain" or "abstention"; its only "don't know" is a cited paper title.
4. **2505.15962, LMLM: returns "unknown" below a similarity threshold. FOUND.** Appendix A.4, "Database and Retrieval Setting", PDF page 19: "If the highest similarity score is below a threshold of 0.6, we return unknown to indicate that no sufficiently similar match was found." Caveat from Appendix B.1 on the same page, FActScore setup: "If no relevant triplet is found, the model continues generation using the plain text string unknown as a fallback. This behavior is untrained and left for future work". On T-REx a miss falls back to standard decoding. So "unknown" is a lookup return value, not a trained abstention.
